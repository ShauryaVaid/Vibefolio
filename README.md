# 🚀 Shaurya Vaid — AI/ML Portfolio

A modern, interactive developer portfolio focused on AI/ML engineering, clean UI design, and smooth user experience.

Built for developers, students, and creators who want a portfolio that feels modern, stylish, and personal instead of looking generic or template-based.

---

## ✨ Features

* ⚡ Smooth and modern UI/UX
* 🎨 Gen-Z inspired dark aesthetic
* 📱 Fully responsive design
* 🧠 AI/ML focused portfolio sections
* 🌌 Interactive hero section
* 🪄 Dynamic project modal system
* 📬 Contact form with fallback handling
* 🔗 Integrated GitHub + LinkedIn links
* ☁️ Optimized for Vercel deployment
* 📂 Open-source and customizable

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ShauryaVaid/shaurya-portfolio.git
```

### 2. Navigate into the project

```bash
cd shaurya-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run locally

```bash
npm run dev
```

---

## 🌐 Deployment

This project is optimized for deployment on:

* Vercel
* Netlify
* GitHub Pages

### Deploy with Vercel

```bash
npm install -g vercel
vercel
```

You can also connect the repository directly to Vercel for automatic deployments on every push.
